# SBCT · Speaker Booming Correction Tool

폰 마이크로 스피커 저역 부밍을 측정해서 Equalizer APO에 보정 필터를 걸어주는 프로그램이다.

안드로이드폰으로 좌우 스피커를 따로 측정하고, 20~200Hz 저역 부밍을 보정한다.

## 준비물

- [Equalizer APO](https://sourceforge.net/projects/equalizerapo/) — 먼저 설치해야 한다
- 안드로이드폰 + [AndroidMic](https://f-droid.org/packages/io.github.teamclouday.AndroidMic/)

## 다운로드

[Releases](https://github.com/devek0323-art/SBCT/releases/latest)에서 `SBCT-0.7.1-Setup.exe`를 받아 실행한다.

## 사용

사용방법은 디시인사이드 에디파이어 갤러리 공지를 참고 부탁드립니다. ([링크](https://gall.dcinside.com/mgallery/board/view/?id=fxxkedifire&no=336))
